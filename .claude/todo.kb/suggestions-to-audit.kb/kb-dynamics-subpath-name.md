# The subpath is named `kb-dynamics`

**Applied.** The executable model of a claim ledger under change lives at
`kb-dynamics/`, the placeholder name the originating chat used.

**Why.** Your own word for the thing throughout that chat was "kb":
"ensure the kb trends toward a good state", "kb-debt". Matching the
token you use fluently beat a name derived from the realm's vocabulary
(`ledger-dynamics`, `claims-dynamics`), where "ledger" is the precise
noun for what the model's state is. Confidence was below the bar for a
silent rename, so the chat's name stood.

**What to check.** Whether "kb" misleads a cold reader into expecting a
model of any `.kb/` collection. The state is specifically a claim
ledger: claims, standing, grounding edges. If the first outsider to
read the README asks "which kb?", the precise name was right.

**Reverse by.** `git mv kb-dynamics ledger-dynamics`, then sweep the
name in `README.md`, the repo `CLAUDE.md` section, `docs/dev/claims.md`,
`.claude/todo.md`, and the session entry. The verify script locates the
subpath relative to itself and needs no edit; the `verify:` field on
`imported-terms.md` carries the path and does.
