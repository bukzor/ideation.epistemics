# The sandbox settles design correctness; the field settles agent reliability

What the harness cannot tell you, stated so it does not quietly grow
into the thing it declined to be: whether the real agent follows the
rules, recognizes near-duplicates, or factors well. That is the field
question, answered by running debt on real ledgers and by postmortem
over their git history -- pick load-bearing claims known to be
misaligned, trace each backward, ask what standing it entered with, what
the agent built on it, and at which move a rule would have caught it.
Cheap, and it observes the real agent instead of a model of one.

Keeping the two apart is what lets the harness need no model of the
agent. What is actually going wrong in a real ledger is a field
question, not a harness one.
