# harness.kb -- maintenance guide

`../harness.md` defines this theory.

## What belongs here

A property the model must satisfy, what a failure of it means, how the
generator stands in for the agent, and how the harness represents what
it cannot judge.

## What does NOT belong here

The build order or the payout test: `../method.md`. A rule's cost:
`../rule-pricing.md`.
