# The properties specify what the field has to measure about the real agent

If every property passes under a random generator, the design does not
depend on agent behavior, the strongest result available. If some
property can only be violated by a generator with a specific bias --
adds without searching, grounds on the nearest claim rather than the
right one -- that bias is the one thing the field has to measure. So the
ladder generates the postmortem questions rather than the postmortem
feeding the ladder: one goes into a ledger's history knowing which two
behaviors to look for.
