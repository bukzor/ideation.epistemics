# "Minimal" is a checkable local condition, not a proof

A rule set is called minimal when a measured local condition holds, not
when an argument for it persuades.

> [!@bukzor] chat.md#L320
> I'm asking about methods to find the minimal rule set. I don't believe you can possibly convince me any proposed rule set is minimal, here.

A rule set is minimal when every adopted rule has marginal benefit above
its cost at the owner's exchange rate, and no unadopted candidate does.
Greedy selection by marginal benefit over cost against the attribution
tally yields a candidate set; running for a period and re-measuring the
debt rate validates it; removal is the second test -- drop a rule, and
if the debt rate does not move the rule was not earning its cost.

In the sandbox the same condition is the fourth property: a rule earns
its place only if some sequence flips when it is removed
(`IMPORTED_FLIP`). Neither is an argument, which is the point.
