# A rule's benefit is attributed from real debt, never argued

Run debt across the real ledgers and, for each item, attribute it: which
candidate rule at which trigger would have prevented or caught it, and
at which move it entered. Git blame gets the commit; the transcript, if
kept, gets the turn. If thirty of forty items are ungrounded claims that
had a ground available at admission, "search before adding" has benefit
thirty over the period those ledgers accumulated. No simulation, nothing
run.

The step that makes sets small is marginal attribution: tally against
the rules already adopted, not per rule in isolation. Checking grounds
at review has high standalone benefit and low marginal benefit once
checking at admission exists, because admission prevents most of what
review would detect.

Costs are the cheap side: firings per period from a marker the agent
emits when a rule fires, tokens per firing read off transcripts, scope
from the ledger's size.
