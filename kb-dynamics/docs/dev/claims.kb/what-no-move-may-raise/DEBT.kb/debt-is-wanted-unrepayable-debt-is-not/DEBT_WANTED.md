# Debt is expected and largely wanted; what is not wanted is debt that can never repay itself

> [!@bukzor] f65fbdf3#L815
> I think it's debatable that debt must not rise. Debt is expected and to a large degree wanted. What's not wanted is debt that can/will never repay itself.

Agent claims that let work proceed before a ruling are the wanted kind:
weightless at first, reviewed when they bear weight. The dynamics claim
is therefore not that debt is monotone but that every debt keeps a
pathway to repayment; what voids the pathway is `UNREPAYABLE`.
