# A question has a terminal state besides answered: closed, nothing depends on it

An open question needs a way out other than an answer: noticed, nothing
rests on it, not worth deciding. Without that state every open question
reads as debt forever, which is how the review filled with minutiae
(`MINUTIAE`). Closing is a move an agent may make on any leaf question
under agent authority, because it takes nothing the owner holds; the
closing act is itself a veto item (`QUEUE_VETO`).
