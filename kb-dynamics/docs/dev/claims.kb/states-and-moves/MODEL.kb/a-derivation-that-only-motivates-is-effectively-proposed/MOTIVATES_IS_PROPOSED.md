# A derivation whose grounds only motivate it is effectively proposed

The fold reads sufficiency before it reads the grounds: a derived claim
whose grounds together entail it is as trustworthy as its weakest
ground; one they only motivate is the agent's reading, effectively
proposed whatever it rests on, and it is its own queue item. This is
`DERIVED_TRUST`'s second criterion made a function of the record, and
the state that demanded it is
`examples/bad-states/a-derivation-whose-arrows-only-motivate.md`.

Of `GROUND_RECORD`'s two fields only sufficiency has entered the model,
as a field of the claim rather than of each arrow, since it is a
property of the grounds together. The arrow's kind waits on a property
that reads it.
