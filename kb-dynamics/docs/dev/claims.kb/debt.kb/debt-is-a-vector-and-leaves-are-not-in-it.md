# Debt is a vector with one component per kind of rot, and leaves are not in it

Debt is a vector, one component per kind of rot, and a node nothing rests
on contributes to none of them. The components:

- load-bearing claims whose effective basis is `proposed`;
- non-atomic claims;
- duplicate pairs;
- draft wording on load-bearing claims.

Not debt: leaf questions nobody depends on, proposed claims with no
descendants, draft wording on leaves. Most of the minutiae that
exhausted the owner's review is zero-debt by this measure, which is why
reviewing it felt pointless (`MINUTIAE`).

This is not the only possible definition. It has the one quality that
matters: it is computable, so "good" stops being a feeling. The weight
per component is the owner's to set and is not derived here.
