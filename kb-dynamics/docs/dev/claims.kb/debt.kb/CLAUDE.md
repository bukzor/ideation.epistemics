# debt.kb -- maintenance guide

`../debt.md` defines this theory.

## What belongs here

A debt component, a property of the function (monotonicity, what is not
debt), or a candidate rule with what it permits or obliges and which
component it targets.

## What does NOT belong here

How a rule is priced: `../rule-pricing.md`. Whether a rule is necessary:
the harness shows that (`../harness.md`).
