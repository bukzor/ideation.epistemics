# Agent permission to edit a claim's text keys off wording, not basis

Draft wording is editable by an agent, and the edit is surfaced to the
owner when the basis is `user`; settled wording is not touched without
asking. What the owner vets is that the rewording preserved intent, a
much smaller review than re-evaluating the idea. This single rule
dissolves the second confusion (`THREE_CONFUSIONS`): the agents that
would not touch owner shorthand were reading the basis as a lock on the
text.
