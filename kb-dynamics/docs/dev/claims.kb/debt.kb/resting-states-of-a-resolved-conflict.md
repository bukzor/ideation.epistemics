# A resolved conflict rests in one of several states, given as examples

Depending on details, the acceptable final states of a resolved
conflict include, not exhaustively:

1. one accepted, one retracted claim
2. two claims, one depending on the other with some elaboration
3. one claim, with references to the removed, unified claim updated
4. three claims, one deeper than both the original, and two extending it

Read against the move table: state 1 is a retraction, state 3 is a
merge, state 2 is an add grounded on the survivor, and state 4 is a
split of the common content followed by two derivations. Whether every
resting state is a composition of the existing moves, so that the
algebra the owner suspects is the move table itself, is a question the
harness can put: enumerate the compositions and ask which conflicts
each clears.
