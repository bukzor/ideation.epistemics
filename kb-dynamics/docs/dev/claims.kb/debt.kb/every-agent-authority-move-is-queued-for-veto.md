# Every move made under agent authority is a queue item for the owner's veto

A move with no license is the agent's own (`AUTHORITY_NOT_HANDS`), and
every such move lands on the review queue as a veto item, ranked like
any other. "Unasked" and "without asking" mean only that the move is
made before the ruling, never that it escapes one. This is said once,
here; the claims that permit particular unasked moves cite it rather
than restating it.
