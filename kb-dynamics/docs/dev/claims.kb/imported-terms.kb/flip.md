# A rule change is graded by which examples flip under it

A rule change is graded by which recorded examples flip under it, and the
flipped set is the change's blast radius. Here a rule's necessity is the
flip test in miniature: a rule earns its place only if some example or
generated sequence flips when the rule is removed. Outer argument not
restated.
