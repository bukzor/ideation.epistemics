# A rule obliges a move when the state requires it

A rule obliges a move when the state requires it, and two rules obliging
incompatible moves at one state is a contradiction. Here obligation in this
sense is what a move must carry with it: a claim added without grounding
must be marked proposed. The other sense, a claim's obligation, is
`obligation.md`. Outer argument not restated.
