# A rule is evaluated on a state and maps it to permitted or obliged moves

A rule is an object that can be evaluated on a state, mapping it to the
moves it permits or obliges; a rule that cannot be evaluated on a state is
prose. Here a rule is a gate a move passes through, a function of the state
and the proposed move. Outer argument not restated.
