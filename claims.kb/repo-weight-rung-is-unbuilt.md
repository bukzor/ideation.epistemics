Repo weight is the realm's least-built rung and its binding constraint
on payout. Chat weight ships and runs (`Skill(llm-claim-ledger)`);
mechanized is prompt-stage research (ACS/FP2). Between them sits the
rung where the operator's sessions actually accumulate knowledge — and
it carries almost none of {TL, RN}:

- **No certificate status.** `asserted` covers a silently-trusted claim
  and a genuinely open one alike; there is no `certified(CHECK)`, so a
  claim backed by a re-runnable verification is indistinguishable from
  one nobody checked.
- **No fiat status.** Operator decree (`stipulated`) has no
  representation, so conclusions can't inherit it as a premise.
- **RP has no substrate to run on.** Nothing walks edges on retraction,
  and the edges could not be walked as they stand: `depends:` is
  documented as context "without implying support or refutation" yet is
  also written claim→claim as genuine support, so a propagator cannot
  tell which retractions should travel. Not latent machinery — an
  untyped edge. The cost is observed: a one-off audit found a live
  rotted edge in `template.python-project`
  (`../2026-07-24-000-warrant-audit.prototype/`).
- **No obligation view.** With edges unwalked, the reverse-dependency
  query that derives obligation has no consumer.
- **`contested` names a state with no resolution procedure.**

Consequence, given `../mission.md`'s ordering: the highest-leverage
work available is closing this gap, because it lands where the daily
work already lives. A fix here reaches every `.kb/` in the fleet; a fix
at the mechanized rung reaches a build that does not yet exist.

The gap analysis is the operator's own, recorded as prior art
(`depends:` above) — this claim adds only that it is now load-bearing,
and that the window to close it is open while v2's epistemic class is
still being designed
(`../questions.kb/how-should-repo-weight-absorb-tl-rn.md`).
