# ACS.kb is a class over llm-kb, not its competitor

In `design-next.kb` class vocabulary, ACS.kb is a **class** on
llm-kb's substrate. It competes with the semantic classes —
`llm-discourse-graph` first — never with llm-kb itself, while pushing
new demands down into the engine: a revision index, edge walking,
view/query verbs, a two-strata mutation discipline.

Corollary the operator drew with it: extending-vs-replacing llm.kb
was a false binary; semantics and physical organization are
independent variables.
