ACS's four presumed statuses (stipulated, asserted, proven, described)
collapse to two base ones at chat weight. `stipulated` = warranted by
fiat; `asserted` = warranted only to the extent it's consistent with
the admitted set — "effectively a question" (operator's own
characterization). `described` is unlabeled prose, not a status;
`proven`/`certified` is read off a claim's premise chain or a named
check at point of use, not declared independently. Consequence: an
`asserted` claim and an `open` claim are the same thing under two
names — the sigil set (`bare`/`?`/`!`) has exactly as many cells as
there are base statuses.
