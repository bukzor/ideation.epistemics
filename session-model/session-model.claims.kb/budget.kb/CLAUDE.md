# budget.kb -- maintenance guide

`../budget.md` defines this theory and stipulates its words.

## What belongs here

One claim per file about the arithmetic model of the instruction layer's token cost, confined to the words `../budget.md` and
its containers admit.

## What does NOT belong here

Anything with a trace or a hidden set in it: that is another theory's, and a claim needing its words imports
it through `why:`.

## When

Add a file when a claim in this vocabulary is made, contested, or ruled.
