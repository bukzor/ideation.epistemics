# A rule change is graded by which examples flip

A rule change is graded by which recorded examples flip under it. The
flipped set is the change's blast radius, and it is the whole of what
"confidence in a proposed change" means here. Formal-system-2 computes blast
radius over a dependency cone; this ledger computes it by re-running rulings.
