# A contradiction is one state at which two rules oblige incompatible moves

A contradiction is one state at which two rules oblige incompatible moves,
reported as the smallest rule set that produces it together with the state that
exhibits it. The minimal-core requirement is formal-system-2's; the exhibiting
state is what this ledger adds.
